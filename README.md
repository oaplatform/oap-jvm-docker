# Dataseat Jvm Docker

Base image for jvm projects.
There are 2 projects in TeamCity that use this repository. The first one (https://build.dataseat.com/viewType.html?buildTypeId=Infrastructure_JvmDocker) creates 2 base images, one with the base jdk and the other one it also adds mongo. These 2 images are pushed to the dataseat docker repository.
The second project in TeamCity (https://build.dataseat.com/admin/editBuild.html?id=buildType:Infrastructure_JvmDockerTagProd) is used to tag with the 'prod' label the validated images. This is intentionally a manual process. When the arm64 and x86_64 images generated by the first job have been validated for use as production base images, we can apply the label and rebuild the projects that use them. All the client projects should use dataseat-jvm:prod or dataseat-jvm-mongo:prod in order to make use of this.
